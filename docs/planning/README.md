# Planning docs live in the CommunityCADPlatform repo

The execution plan, API audit, feature overview, spike report and phase reports for
this plugin are maintained in **one place**:

`CommunityCADPlatform/docs/planning/`
(https://github.com/mloy97/CommunityCADPlatform/tree/main/docs/planning)

- `execution-plan.md`: the plan, phase status, and what changed from the plan as built
- `feature-overview.md`, `api-audit.md`, `phase0-spike-report.md`
- `reports/`: per-phase implementation and deploy reports

This repo does not carry a copy. Edit the files there and link to them from here.
The earlier branch `claude/create-docs-planning-dir-0w1fv4` held a copy; its content
was moved to the platform repo on 2026-09-23 and the branch can be deleted.
